EL ÑAÑO — HOME PAGE
Open index.html through any static server (VS Code Live Server works) or upload the folder as-is. GSAP and fonts are bundled.

PHOTOS
Every photo tries, in order: your local file in /img -> El Ñaño's official image URL -> a crop of their hero photo -> brand pattern.
To use your own photography, drop files into /img with these names:
  logo.png  hero-1.jpg hero-2.jpg hero-3.jpg  story-1.jpg story-2.jpg  atmosphere.jpg  miami.jpg
  dish-1.jpg (encebollado)  dish-2.jpg (camarones)  dish-3.jpg (mariscos)  dish-4.jpg (arroz con maduro)
Dish photos are shown in circles, so square top-down shots work best.

MOTION
1. Hero: full-screen image + headline transitions (scale/blur dissolve), progress-ring "next" button, swipe on mobile.
2. Menu: pinned scroll-scrubbed scene. Plate travels across the stage, garnish drifts on separate depth layers, copy and colour change.
3. Editorial layers: story, locations and closing section use different-speed parallax and masked reveals.
prefers-reduced-motion gives a static, fully readable page. EN/ES toggle in header.
